# Documentation Images

This folder contains images for the GitHub repository documentation.

## Image Generation Examples
- `sample_generations/` - Example images generated by the ML-MDM model
- `ui_screenshots/` - Screenshots of the Gradio web interface
- `performance_charts/` - Performance metrics and benchmarks

## Horizontal Scaling & Deployment
- `load_balancer_dashboard/` - Screenshots of the real-time monitoring dashboard
- `kubernetes_deployment/` - Kubernetes cluster and pod management screenshots
- `docker_setup/` - Docker container and compose setup images
- `architecture_diagrams/` - System architecture and flow diagrams

## Usage
Add your images to the appropriate subfolder and reference them in the main README.md:

```markdown
![Load Balancer Dashboard](docs/images/load_balancer_dashboard/dashboard_screenshot.png)
![Kubernetes Deployment](docs/images/kubernetes_deployment/pods_running.png)
```

## File Naming Convention
- Use descriptive names: `dashboard_real_time_monitoring.png`
- Use lowercase with underscores: `kubernetes_pods_status.png`
- Include version numbers if needed: `performance_benchmark_v1.png`
